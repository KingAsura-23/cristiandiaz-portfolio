Challenge

Given an ELF binary that prompts for a password and prints "Access granted" if the input is correct. No source. No symbols stripped beyond main. Replace with your real challenge text. 

./challenge
Enter the secret: hunter2
Wrong.

Recon

Standard first-look on any binary: 

file ./challenge
checksec --file=./challenge
strings ./challenge | grep -i flag
nm ./challenge | head

Notes: 64-bit ELF, no PIE, no canaries, partial RELRO. strings turned up some hex blobs but no obvious flag. Promising.

Static Analysis

Loaded the binary into Ghidra and jumped to main. The decompiler showed a per-character XOR check against a hardcoded buffer: 

// Decompiled - simplified
int main(void) {
    char input[64];
    char key[] = "\x37\x21\x5c\x...";
    printf("Enter the secret: ");
    fgets(input, 64, stdin);
    for (int i = 0; i < strlen(input); i++) {
        if ((input[i] ^ 0x42) != key[i]) {
            puts("Wrong.");
            return 1;
        }
    }
    puts("Access granted!");
    system("/bin/sh");
    return 0;
}
Drop the Ghidra decompile screenshot here once you have one.

Approach

Once I saw it was a straight XOR check against a constant key, the solve is just inversion: input[i] = key[i] ^ 0x42. No need to run it under gdb at all.

What I tried first

Walk through the path that wasn't optimal. e.g. "I initially tried ltrace hoping the compare would be in strcmp — it wasn't because the check is character-by-character in a loop."

The pivot

Spotting the constant 0x42 XOR pattern in Ghidra was the moment. From there it's a one-liner.

Solution

key = bytes.fromhex("37215c...")  # extracted from .rodata
flag = bytes(b ^ 0x42 for b in key)
print(flag.decode())

Piped it back into the binary: 

python3 solve.py | ./challenge
FLAG » picoCTF{REDACTED_REPLACE_WITH_YOUR_FLAG}

Lessons Learned

  • Cheap XOR "encryption" against a constant is trivial — if I see a single repeating byte in a check loop, just invert.
  • Ghidra's decompiler reads close enough to C that you can often skip dynamic analysis entirely on this kind of crackme.
  • Pull .rodata early — constants are often the answer.
