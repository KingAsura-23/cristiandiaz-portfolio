Sentinel-Lite

AWS Security Scanner

Problem

Cloud environments grow fast, and misconfigurations — public S3 buckets, overly permissive IAM policies, open security groups — are a leading cause of data breaches. Manual audits don't scale.

Solution

Sentinel-Lite is a Python CLI tool that connects to AWS via boto3 and scans IAM policies, S3 bucket ACLs, and security group rules. It outputs a structured JSON report highlighting critical findings ranked by severity.

Tech Stack

  • Python
  • boto3
  • AWS IAM
  • AWS S3
  • pytest
  • GitHub Actions

Challenges

Deep understanding of AWS IAM least-privilege principles, S3 public access block settings, and how to structure a modular scanner that can grow into a full security platform.
