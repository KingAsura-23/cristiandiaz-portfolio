Health Data Platform

Problem

Healthcare organizations need a secure, centralized platform to ingest, store, and analyze patient data while maintaining HIPAA-aligned access controls and audit trails.

Solution

Built a full-stack health data platform with a Flask REST API, PostgreSQL database, and React frontend. Implemented role-based access, data validation pipelines, and automated E2E test coverage with Playwright.

Tech Stack
